# Contributing

## Local Development

```bash
[install command]
[run command]
```

## Branches

- `main`: production-ready code.
- Feature branches: `feature/[short-name]`.
- Fix branches: `fix/[short-name]`.

## Before Opening A PR

- [ ] Code is formatted.
- [ ] Lint passes.
- [ ] Tests pass.
- [ ] Docs updated if behavior changed.
- [ ] Config changes are reflected in `.env.example`.

## Code Review Expectations

Reviewers should check:

- Correctness
- Test coverage
- Security impact
- Operational impact
- Readability
- Backward compatibility

## Commit Style

Use clear, action-oriented commit messages:

```text
Add user session expiration
Fix invoice status validation
Document deployment rollback
```
