# Incident Response

## Severity Levels

| Severity | Meaning | Response |
| --- | --- | --- |
| SEV1 | Major outage, data loss, security incident | Immediate response |
| SEV2 | Degraded critical workflow | Same-day response |
| SEV3 | Non-critical defect | Scheduled fix |

## First 10 Minutes

- [ ] Confirm the incident.
- [ ] Assign incident owner.
- [ ] Create incident channel or tracking issue.
- [ ] Check recent deploys.
- [ ] Check error rate, latency, traffic, and logs.
- [ ] Decide whether to rollback.

## Postmortem

Answer:

1. What happened?
2. What was the impact?
3. Why did it happen?
4. How was it detected?
5. What prevented faster detection or recovery?
6. What actions prevent recurrence?
