# Pre-Release Checklist

- [ ] Release notes are drafted.
- [ ] All required tests pass.
- [ ] Build artifact is reproducible.
- [ ] Database migrations are reviewed.
- [ ] Backward compatibility is checked.
- [ ] Config changes are documented.
- [ ] Secrets are present in target environment.
- [ ] Monitoring dashboards are available.
- [ ] Alerts are active.
- [ ] Rollback path is tested or understood.
- [ ] Support/operations notes are written.
