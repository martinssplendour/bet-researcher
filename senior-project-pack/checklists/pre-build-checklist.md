# Pre-Build Checklist

- [ ] Problem and users are clear.
- [ ] Main workflows are documented.
- [ ] Non-goals are documented.
- [ ] Tech stack is justified.
- [ ] Repo structure is chosen.
- [ ] `AGENT_CODING_RULES.md` is copied or adapted.
- [ ] Modular boundaries are clear before implementation starts.
- [ ] README exists.
- [ ] `.env.example` exists.
- [ ] First ADR exists.
- [ ] Architecture overview exists.
- [ ] Test strategy exists.
- [ ] Security assumptions are documented.
- [ ] Deployment target is known.
