# Handoff Checklist

- [ ] README is current.
- [ ] Architecture overview is current.
- [ ] Main workflows are documented.
- [ ] Local setup works from a clean machine.
- [ ] Environment variables are documented.
- [ ] Deployment process is documented.
- [ ] Rollback process is documented.
- [ ] Tests and quality gates are documented.
- [ ] Known risks are documented.
- [ ] Open decisions are documented.
- [ ] Credentials and access ownership are documented outside the repo.
- [ ] Monitoring and logs are linked.
- [ ] Support contact or owner is listed.
